## Практична 27

1. Які частини програми виконують ролі Model, View та Controller?
	- Model: Book, BookModel.
	- View: ConsoleView.
	- Controller: BookController.
2. Чому таку структуру можна вважати реалізацією MVC?
	- Тому що дотримано головний принцип MVC: розділення відповідальності.
3. Які дії користувача підтримує програма?
	- Додавання книги.
	- Перегляд книг.
	- Пошук книг.
	- Видалення книг.
4. Як Controller взаємодіє з Model і View?
	- Викликає методи View для отримання команд від користувача й передачі сформованих результатів.
	- Передає дані між методами View й Model.
5. Як обробляються некоректні вхідні дані?
	- Controller ловить помилки й повідомляє про них через View.
