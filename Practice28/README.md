## Практична 28

1. Який клас є основним сервісом, а який — його залежністю?
	- Основним класом є BookService, його залежністю є класи інтерфейсу IBookRepository.
2. Де саме у вашій програмі відбувається впровадження залежності?
	- Через конструктор BookService.
3. Як ви замінили одну реалізацію іншою, не змінюючи основний сервіс?
	- Шляхом передачі різних об'єктів до конструктора.
4. Чим такий підхід зручніший за створення залежності всередині сервісу?
	- Використовується принцип слабкого зв'язування. Сервіс не залежить від конкретної реалізації. Це спрощує заміну компонентів та подальшу роботу з кодом.
